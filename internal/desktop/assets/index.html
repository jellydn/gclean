  2. Create an OAuth client with application type Desktop app.
  3. Choose the downloaded file in Settings. Its contents stay local.

PERMANENT DELETION

Empty Trash capability

Disabled

Permanent deletion is never enabled by a saved setting. It requires a separate full-access OAuth login and the desktop --allow-purge startup flag. Empty Trash deletes all Gmail Trash, including messages not moved by gclean, and cannot be undone.

gclean login --allow-permanent-delete
gclean desktop --allow-purgeRe-authentication and restart required
