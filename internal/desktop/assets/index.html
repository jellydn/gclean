ONE-TIME SETUP

Connect your Gmail account

gclean uses a Desktop OAuth client and requests only permission to read metadata and move messages to or from Trash.

  1. Enable the Gmail API in Google Cloud Console.
  2. Create an OAuth client with application type Desktop app.
  3. Save the download as ~/.config/gclean/credentials.json.
